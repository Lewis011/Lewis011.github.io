五月月报

本月的主要内容是完成个人博客的搭建与上线。

整个过程从上周开始，基于 Hexo 框架与 GitHub Pages 服务实现。前期主要工作包括环境配置、主题选择与基础样式调整，解决了部署过程中出现的网络连接问题，以及背景图片路径错误、加载失败等常见问题。目前博客已完成基础功能上线，后续将持续优化样式与内容。

除博客相关外，本月其余时间以课程学习与企业实习为主，夹杂对leetcode刷题记录和java学习感受，整体节奏平稳。
